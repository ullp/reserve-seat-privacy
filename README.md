# Reserve Seat and Parking — privacy policy

Public hosting for the privacy policy of the **Reserve Seat and Parking** app
(`com.reserveseat.app`), so the Google Play and Apple App Store listings have a
reachable, unauthenticated URL.

- Published: <https://ullp.github.io/reserve-seat-privacy/privacy-policy.html>
- Imprint anchor: <https://ullp.github.io/reserve-seat-privacy/privacy-policy.html#imprint>

## Why this repo exists

The application repository (`ullp/reserve-seat-and-parking`) is **private**, and
GitHub only serves a private repository's Pages site to people with repository
access — which the stores cannot use. This repository therefore contains nothing
but the policy.

## Source of truth

`privacy-policy.html` is a copy of `public/privacy-policy.html` in the
application repository (the Markdown master is `PRIVACY_POLICY.md`). **Update the
application repository first, then copy the rendered file here and push** — the
`G19` checklist item in that repository tracks the procedure.
